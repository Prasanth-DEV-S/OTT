                     MVI architecture

                                  User
                                    │
                                    ▼
                                  Intent
                                    │
                                    ▼
                               ViewModel
                                    │
                            ┌───────┴────────┐
                            │                │
                            ▼                ▼
                          State            Effect
                            │                │
                            ▼                ▼
                            UI           Navigation/
                                         one-time event


                     For example, the user selects a video.
                            TV Remote
                               │
                               ▼
                            Video Card
                               │
                               ▼
                            VideoClicked(video)
                               │
                               ▼
                            HomeViewModel
                               │
                               ▼
                            HomeEffect.OpenPlayer(video)
                               │
                               ▼
                            TvHomeRoute
                               │
                               ▼
                            TvPlayerActivity

                     The same flow works for Mobile:
                          Mobile Card
                              │
                              ▼
                          VideoClicked(video)
                              │
                              ▼
                          HomeViewModel
                              │
                              ▼
                          HomeEffect.OpenPlayer(video)
                              │
                              ▼
                          MobileHomeRoute
                              │
                              ▼
                          MobilePlayerActivity
